# Shared repository standards

Canonical guidance: [infoe-labs/new-repo](https://github.com/infoe-labs/new-repo).
Read its NEW_REPO_INSTRUCTIONS.md and CONTRIBUTING.md for setup and delivery.
Preserve stronger project-specific policies and required checks. Shared changes
use focused PRs, passing CI and protected main; no administrator/agent bypass.

Pages sites must show a verified clickable Live site link immediately below the
README title. Keep Actions defaults read-only, dismiss stale approvals and require
resolved conversations, strict checks and linear history. Keep privacy hooks
local and untracked. Central monitoring is read-only; remediation uses PRs.
